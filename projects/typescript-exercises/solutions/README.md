# TypeScript exercises: solutions

Model solutions for the exercises in part 2 of the slides (chapters 2–11). There is one file per chapter in `src/`.

Exercises that ask "what happens?" are answered in comments. Lines marked `// @ts-expect-error` show code that TypeScript should reject. If one of them stops being an error, `npm run typecheck` fails.

```bash
npm install
npm run typecheck
npm test
```
